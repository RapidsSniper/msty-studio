# Msty Studio

### The smoothest way to run and compare AI models

Msty Studio is a beautiful desktop AI client focused on model comparison and local inference. Run models side by side, test prompts across different configurations, and manage your local AI stack from one elegant app.

<br>

---

## Features

| | |
|:---|:---|
| **Side-by-Side Mode** | Run the same prompt through multiple models simultaneously |
| **Model Stacks** | Download and manage Ollama, LM Studio, and remote API models together |
| **Prompt Library** | Save and organize your best system prompts and templates |
| **Conversation Branching** | Fork any conversation to explore different response paths |
